# Prince.exe — Prince Kumar Mishra

My interactive portfolio: software projects, robotics, education and experience.

Website: https://mishra-prince.github.io/

## Features

- Retro interface, responsive project flashcards and case studies
- Stationary photo ID with a physics-driven fabric lanyard
- Full uncropped photo rendered in dot matrix on the reverse
- Verified LinkedIn, GitHub and WhatsApp QR links
- Resume downloads, keyboard navigation and reduced-motion controls

## Hosting

GitHub Pages publishes the main branch from the repository root. This is a static HTML, CSS and JavaScript site with local fonts and assets. No build step or ChatGPT login is required.

Phone tilt requires a compatible phone browser and permission when prompted.
